# 地图编辑器

基于《富甲天下4》的地图设计开发的地图编辑器。

## 功能特性

### 地图元素
- **道路**: 主要路线，使用棕色显示
- **建筑**: 占地 2格入口 + 2×2正方形 = 共6格，使用蓝色显示
  - 入口在道路上（标记为"入"）
  - 建筑体在道路两侧（深蓝色，显示建筑ID）
- **城池**: 占地 2格入口 + 2格名称区 + (1-3)×2格建筑槽位 = 共6-10格
  - 入口在道路上（金色，标记为"入"）
  - 名称区（深金色，标记为"名"）
  - 建筑槽位（浅金色，标记为"槽"）
- **分叉路口**: 带有箭头标记的分叉点，使用红色箭头显示

### 操作方式

#### 工具栏
- **道路工具**: 点击并拖拽在网格上绘制道路
- **建筑工具**: 拖拽放置建筑物（自动占用6格）
  - 点击已有建筑可选中（绿色高亮）
- **城池工具**: 拖拽放置城池（默认1个槽位）
  - 点击已有城池可选中
- **分叉工具**: 点击放置分叉路口
- **擦除工具**: 点击擦除地图元素（自动删除整个建筑/城池）

#### 建筑和城池特殊操作
- **鼠标滚轮**: 在城池上滚动鼠标滚轮可以修改建筑槽位数（最小1，最大3）
  - 系统会自动重新放置城池以适应新的槽位数
- **R键**: 点击选中建筑/城池后，按R键可以旋转其放置位置（道路左侧或右侧）
  - 系统会检查空间是否足够，如果不足则不会旋转

#### 文件操作
- **保存**: 点击"保存"按钮或按 Ctrl+S 保存地图到 `map.json`
- **加载**: 点击"加载"按钮或按 Ctrl+O 从 `map.json` 加载地图

### 界面布局
- **主网格区域**: 40×30的网格，用于绘制地图
- **工具栏**: 底部工具栏包含所有编辑工具和保存/加载按钮
- **侧边栏**: 右侧显示当前工具和操作说明

## 使用方法

### 启动编辑器
```bash
python -m MapEditor.editor
```

或使用启动脚本：
```bash
start_editor.bat
```

### 绘制地图流程
1. 选择"道路"工具，点击拖拽绘制主要路线
2. 选择"建筑"工具，拖拽到道路上放置（会自动占用6格）
   - 入口在道路上，建筑体默认在左侧
3. 选择"城池"工具，拖拽到道路上放置（默认1个槽位）
   - 入口在道路上，名称区和槽位默认在左侧
4. 点击选中城池，使用鼠标滚轮调整槽位数（1-3）
5. 点击选中建筑/城池，按R键切换在道路的左侧或右侧
6. 需要分叉时，选择"分叉"工具点击放置
7. 使用"擦除"工具点击建筑/城池清除（会自动删除整个结构）
8. 完成后按Ctrl+S或点击"保存"按钮保存地图

## 地图文件格式

地图保存为JSON格式（压缩格式），包含以下信息：
- `width`, `height`: 网格尺寸
- `roads`: 道路单元格数组
- `buildings`: 建筑物数组
- `cities`: 城池数组

### RoadCell 结构
```json
{
  "x": 10,
  "y": 5,
  "entry": null,     // null=普通道路, 1=建筑入口, 2=城池入口
  "id": null,        // 入口对应的建筑/城池ID
  "direction": null  // null=普通道路, 0-3=分叉口方向(UP/RIGHT/DOWN/LEFT)
}
```

**注意**：
- 普通道路：`entry=null, id=null, direction=null`
- 建筑入口：`entry=1, id=建筑ID, direction=null`
- 城池入口：`entry=2, id=城池ID, direction=null`
- 分叉口：`entry=null, id=null, direction=0-3`

### Building 结构
```json
{
  "id": 1,
  "name": "酒楼",  // 可手动修改
  "x": 11,        // 入口x坐标
  "y": 5,         // 入口y坐标
  "direction": 0  // 方向: 0=UP, 1=RIGHT, 2=DOWN, 3=LEFT
}
```

### City 结构
```json
{
  "id": 2,
  "name": "临安城",  // 可手动修改
  "x": 20,          // 入口x坐标
  "y": 10,          // 入口y坐标
  "direction": 0,   // 方向: 0=UP, 1=RIGHT, 2=DOWN, 3=LEFT
  "lv": 3,
  "people": 1000,
  "army": 500,
  "slots": [43, 0, null]  // null=不可用, 0=空, 整数=城池建筑ID
}
```

### 完整示例
```json
{
  "width": 40,
  "height": 30,
  "roads": [
    {"x": 10, "y": 5, "entry": null, "id": null},
    {"x": 11, "y": 5, "entry": 1, "id": 1},
    {"x": 12, "y": 5, "entry": 1, "id": 1}
  ],
  "buildings": [
    {"id": 1, "name": "酒楼"}
  ],
  "cities": [
    {"id": 2, "name": "临安城", "lv": 3, "people": 1000, "army": 500, "slots": [43, 0, null]}
  ]
}
```

**注意**: 编辑器保存时会生成默认名称，建筑名称、城池属性和槽位建筑需要在JSON文件中手动修改。

## 技术实现

### 代码结构
- 使用Pygame进行图形界面渲染
- 采用面向对象设计，主要类包括：
  - `MapEditor`: 编辑器主类
  - `MapCell`: 地图单元格类
  - `CellType`: 单元格类型枚举
  - `Tool`: 工具类型枚举
  - `Direction`: 方向枚举
  - `BuildingSide`: 建筑侧边枚举

### 参考M3K4的设计
- 网格系统与M3K4的游戏网格类似
- 使用类似的颜色方案和UI布局
- 采用相同的代码组织结构（枚举、类、函数分离）
