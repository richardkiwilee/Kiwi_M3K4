# Kiwi_M3K4
根据游戏《富甲天下4》制作的基于grpc多人联机游戏

# 地图设计
地图使用标准的四边形网格，所有建筑物和城池的入口占地均为2格。建筑物和城池均放在主要路径的两侧，建筑物战地为2\*2，城池根据槽位容量（最低1，最高3）从2\*2至4\*2。
一般情况下，主要路线是不分叉的，对于分叉的情况，交汇处的单元格有箭头标记，表示当前的分叉选择方向，每当分叉被使用一次，箭头按顺时针旋转到下一个可达的方向，如果玩家前进方向与箭头指向正好相反，则先触发一次箭头旋转。

# 界面设计
用户界面分为三个部分，首先以8：2分割上下，然后在下半部分，以9：1分割，总共分成3个部分。上方地图和其他窗口（如触发选项等）的操作空间，左下角为玩家槽位，右下角为展示页面，右下角为日志输出。
玩家槽位从左往右依次是：矩形的4个玩家槽位，槽位展示内容从上往下依次是主公名称、声望与城池数量，本队武将数量、本队兵数、金钱。
然后是一个标签分页，标签为武将、锦囊、机关、建筑图纸、持有武器
然后是垂直排列的一组按钮，从上到下分别是主公、武将、城池。

# 地图编辑器
基于上述的地图设计，开发一个用户界面地图编辑器，类似画图，使用鼠标对地图进行填色绘制主要路线，使用拖拽放置建筑物和城池。
当点选城池时，使用滚轮修改建筑槽位数，最大3，最小1。使用R旋转放置在道路的左侧或是右侧。
